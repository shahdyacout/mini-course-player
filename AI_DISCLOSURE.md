# AI Use Disclosure

I used AI tools (primarily Claude and ChatGPT) as development assistants throughout this assessment.

The AI was mainly used to:
- Discuss the overall project architecture and compare different architectural approaches.
- Suggest folder structures and naming conventions.
- Explain Flutter concepts, Clean Architecture, and state management decisions.
- Review parts of the implementation and suggest improvements or alternative approaches.
- Help troubleshoot errors and answer implementation questions during development.

I made the architectural decisions, implemented the project, integrated the different layers, tested the application, and adjusted the generated suggestions whenever they did not fit the project requirements.

To verify the implementation, I:
- Ran `flutter analyze` and resolved reported issues.
- Ran the unit and widget tests.
- Manually tested the application on a device, including course loading, video playback, progress persistence, resume playback, and offline/error scenarios.
- Reviewed the code to ensure the dependency direction follows Clean Architecture principles.
